# การประเมิน UI ตามหลัก 10 Usability Heuristics ของ Jakob Nielsen

เอกสารนี้สรุปว่าแต่ละหลักถูกนำมาใช้กับ Movemai อย่างไร: ปัญหาที่พบในเวอร์ชันก่อน → สิ่งที่แก้ → ไฟล์ที่เกี่ยวข้อง
(ผู้ใช้หลักคือนักเรียน ใช้งานบนมือถือ ขณะเดินอยู่กลางแจ้ง)

ระดับความรุนแรง: 🔴 สูง (ทำให้ใช้งานต่อไม่ได้) · 🟠 กลาง (สับสน/เสียเวลา) · 🟡 ต่ำ (ขัดเกลา)

---

## 1. Visibility of system status — ให้ผู้ใช้รู้เสมอว่าระบบกำลังทำอะไร

| ปัญหาที่พบ | ระดับ | สิ่งที่แก้ |
|---|---|---|
| หน้าสัตว์เลี้ยง/สถิติค้างที่ "กำลังโหลด…" ไม่รู้จบเมื่อเกิด error | 🔴 | แสดงตัวหมุน + ข้อความ "ใช้เวลานานกว่าปกติ" หลัง 8 วินาที และแสดงสาเหตุพร้อมปุ่มลองใหม่ (`MeGate`) · ทุกคำขอหมดเวลาใน 20 วินาที |
| ปุ่ม "สุ่มจุดภารกิจ" เป็นสีจาง แต่ไม่บอกว่าทำไมกดไม่ได้ | 🔴 | แสดงเหตุผลใต้ปุ่มเสมอ เช่น "กำลังรอสัญญาณ GPS…", "ต้องอยู่ในเขตโรงเรียน" (`MissionPanel`) |
| ระหว่างภารกิจ ไม่รู้ว่าระบบกำลังตรวจตำแหน่งอยู่หรือไม่ | 🟠 | แสดง "ตรวจตำแหน่งล่าสุด X วินาทีที่แล้ว" และ "ยืนยันตำแหน่ง 1/3" เป็นตัวอักษรคู่กับแถบ |
| ไม่เห็นจำนวนเหรียญในบางหน้า | 🟡 | หัวหน้ามาตรฐานแสดงเหรียญทุกหน้า (`PageHeader`) |

## 2. Match between system and the real world — ใช้ภาษาและหน่วยที่ผู้ใช้คุ้นเคย

| ปัญหาที่พบ | ระดับ | สิ่งที่แก้ |
|---|---|---|
| "GPS ±8 ม." เป็นศัพท์เทคนิค เด็กไม่รู้ว่าดีหรือแย่ | 🟠 | ป้ายสี "GPS ดีมาก / ดี / อ่อน / ตำแหน่งโดยประมาณ" (`GpsChip`) |
| บอกแค่ระยะทางเป็นเมตร | 🟡 | เพิ่ม "เดินราว N นาที" ซึ่งเข้าใจง่ายกว่า |
| ข้อความ "อยู่นอกพื้นที่" ไม่บอกว่าไกลแค่ไหน | 🟡 | บอกระยะห่างจากโรงเรียน และอ้างถึง "กรอบสีส้มบนแผนที่" ที่มองเห็นได้จริง |

## 3. User control and freedom — ออกจากสิ่งที่ทำพลาดได้ง่าย

| ปัญหาที่พบ | ระดับ | สิ่งที่แก้ |
|---|---|---|
| กดซื้อของแต่งตัวแล้วเสียเหรียญทันที ไม่มีทางถอย | 🟠 | หน้าต่างยืนยันพร้อมปุ่ม "ยกเลิก" (ดูข้อ 5) |
| (มีอยู่แล้ว) | — | ยกเลิก/เปลี่ยนจุดภารกิจได้ ถอดของแต่งตัวได้ สลับสัตว์เลี้ยงได้ ซ่อนชื่อจากกระดานอันดับได้ |

## 4. Consistency and standards — หน้าตาและพฤติกรรมเหมือนกันทั้งแอป

| ปัญหาที่พบ | ระดับ | สิ่งที่แก้ |
|---|---|---|
| หัวหน้าแต่ละหน้าไม่เหมือนกัน (บางหน้ามีเหรียญ บางหน้าไม่มี ปุ่มรีเฟรชคนละแบบ) | 🟠 | `PageHeader` เดียวกันทุกหน้า: ชื่อหน้า + คำอธิบาย + เหรียญ + ปุ่ม "?" |
| สถานะกำลังโหลดคนละแบบ (ข้อความเปล่า / ตัวหมุน / ไม่มีเลย) | 🟡 | ใช้ตัวหมุนแบบเดียวกัน และหน้าตั้งค่ารอข้อมูลก่อนแสดง (`MeGate`) |
| (มีอยู่แล้ว) | — | สีปุ่ม: หลัก = ส้มแดง, ยืนยันอันตราย = แดง · กล่องข้อความใช้สีตามความหมาย (สำเร็จ=เขียว เตือน=เหลือง ผิดพลาด=แดง) |

## 5. Error prevention — ป้องกันไม่ให้เกิดความผิดพลาดตั้งแต่แรก

| ปัญหาที่พบ | ระดับ | สิ่งที่แก้ |
|---|---|---|
| ซื้อของผิดชิ้นโดยไม่ตั้งใจ | 🟠 | ยืนยันก่อนซื้อ แสดงราคาและเหรียญที่จะเหลือ |
| พิมพ์รหัสผ่านผิดโดยไม่รู้ตัว (มองไม่เห็น) | 🟠 | ปุ่ม "แสดง/ซ่อน" รหัสผ่าน (`Field`) |
| พิมพ์ชื่อเล่นยาวเกินแล้วโดนตัด | 🟡 | ตัวนับ "8/20" ข้างช่องชื่อเล่น |
| (มีอยู่แล้ว) | — | ปุ่มเริ่มภารกิจกดไม่ได้เมื่อเงื่อนไขไม่ครบ · ยืนยันก่อนยกเลิกภารกิจ · กรองชื่อเล่นไม่สุภาพ |

## 6. Recognition rather than recall — ให้เห็น ไม่ต้องจำ

| ปัญหาที่พบ | ระดับ | สิ่งที่แก้ |
|---|---|---|
| ไม่มีคำอธิบายสัญลักษณ์บนแผนที่ (จุดฟ้า ธง กรอบส้ม) | 🟠 | ป้าย "ฉัน" บนจุดผู้เล่น + หัวข้อ "สัญลักษณ์บนแผนที่" ในหน้าวิธีเล่น |
| ต้องจำขั้นตอนการเล่นเอง | 🟠 | หน้าวิธีเล่น 4 ขั้น เปิดได้จากปุ่ม "?" ทุกหน้า |
| (มีอยู่แล้ว) | — | การ์ดภารกิจแสดงชื่อจุด คำใบ้ ทิศ และรางวัลตลอด · ร้านแสดงผลของอาหารแต่ละอย่าง · ชนิดสัตว์ที่ล็อกบอกเลเวลที่ต้องการ |

## 7. Flexibility and efficiency of use — ทางลัดสำหรับคนที่ใช้บ่อย

| ปัญหาที่พบ | ระดับ | สิ่งที่แก้ |
|---|---|---|
| ต้องเปิดเบราว์เซอร์แล้วพิมพ์ที่อยู่ทุกครั้ง | 🟡 | ปุ่ม "ติดตั้งแอปบนหน้าจอโฮม" (Android) / วิธีติดตั้ง (iPhone) ในหน้าตั้งค่า (`InstallApp`) |
| (มีอยู่แล้ว) | — | ปุ่ม 🎯 กลับมาที่ตำแหน่งตัวเอง · ปุ่ม "ไปให้อาหาร" ทันทีหลังได้เหรียญ · ระบบตรวจถึงจุดเองอัตโนมัติ ไม่ต้องกดอะไร |

## 8. Aesthetic and minimalist design — แสดงเฉพาะสิ่งที่จำเป็น

| ปัญหาที่พบ | ระดับ | สิ่งที่แก้ |
|---|---|---|
| กล่องแจ้งปัญหาตำแหน่งยาวหลายบรรทัด บังแผนที่ | 🟠 | เหลือหัวข้อ + 1 บรรทัด + ปุ่ม · วิธีตั้งค่าแยกตามรุ่นมือถือซ่อนไว้ใน "ดูวิธีเปิด" |
| แผนที่ดาวเทียมรกตา ตัวหนังสือบนแผนที่อ่านยาก | 🟠 | แผนที่ถนนโทนขาว ให้จุดผู้เล่น/จุดหมาย/เขตโรงเรียนเด่น |

## 9. Help users recognize, diagnose, and recover from errors

| ปัญหาที่พบ | ระดับ | สิ่งที่แก้ |
|---|---|---|
| error ของ server ไม่บอกสาเหตุ | 🔴 | ข้อความภาษาไทยแยกตามสาเหตุ (เช่น กุญแจ server ผิด, ยังไม่ได้สร้างฐานข้อมูล) + หน้า `/api/health` สำหรับผู้ดูแล |
| ปัญหาตำแหน่งบอกอาการ แต่ไม่มีทางแก้ในหน้าจอ | 🟠 | ปุ่ม "ลองใหม่" ในกรณีปฏิเสธสิทธิ์ / หาตำแหน่งไม่เจอ / ไม่ได้ตำแหน่งใหม่ |
| (มีอยู่แล้ว) | — | คำแนะนำเมื่อ GPS อ่อน / เดินเร็วผิดปกติ / เวลาเครื่องไม่ตรง · ข้อความ error ของการล็อกอินเป็นภาษาไทย |

## 10. Help and documentation

| ปัญหาที่พบ | ระดับ | สิ่งที่แก้ |
|---|---|---|
| ไม่มีคู่มือในแอป | 🟠 | หน้า "วิธีเล่น" (ขั้นตอน + สัญลักษณ์ + คำถามที่พบบ่อย) เปิดอัตโนมัติครั้งแรกหลังยอมรับคำเตือนความปลอดภัย และเปิดได้จากปุ่ม "?" ทุกหน้า / เมนูตั้งค่า (`HelpModal`) |
| (มีอยู่แล้ว) | — | หน้าความเป็นส่วนตัว (`/privacy`) · คำเตือนความปลอดภัยก่อนเล่น |

---

## สิ่งที่ยังไม่ได้ทำ (เสนอไว้สำหรับรอบถัดไป)
- ทดสอบกับนักเรียนจริง (usability test 5 คน) เพื่อยืนยันว่าแก้ปัญหาได้จริง — การประเมินนี้เป็นแบบ heuristic โดยผู้พัฒนา ไม่ใช่ผลทดสอบกับผู้ใช้
- โหมด "เก็บมือถือ" (สั่น + กันจอดับ) เพื่อให้ไม่ต้องดูจอขณะเดิน
- ปรับขนาดตัวอักษรได้ / โหมดคอนทราสต์สูง
